## Control Flow

### if와 when

kotlin에서는 if와 when이 있을때, when 사용을 추천함
1. 코드를 쉽게 읽을 수 있게 쓸 수 있음
2. 다른 케이스 추가에 효과적
3. 코드 오류 줄여줌

if 문
```kotlin
val d: Int
val check = true

if (check){
    d = 1
} else {
    d = 2
}
print(d) // 1
```

코틀린은 삼항연산자가 없으며, python처럼 한 줄로 표기도 가능
```kotlin
val a = 1
val b = 2
println( if (a > b) a else b) // 2
```

when 문
1. 조건에 넣으려는 걸 괄호()안에 넣기
2. 추가할 케이스를 중괄호{}안에 넣기
3. 각 분기에서 사용하여 -> 로 동작 구분
4. else 무조건 써야함!! 안쓰면 에러남
```kotlin
val obj = "Hello"
when (obj){
    "1" -> println("One")
    "Hello" -> println("Greeting")
    else -> println("Unknown")
} // Greeting
```

when의 결과를 바로 넣을수도 있다.
```kotlin
val obj = "안녕하세요"
val result = when (obj){
    "1" -> println("One")
    "Hello" -> println("Greeting")
    else -> println("Unknown")
} // Greeting
println(result) // Greeting
```

when을 쓸 때, ()없이 바로 사용도 가능
```kotlin
val trafficLightState = "Red"
val trafficAction = when {
    trafficLightState == "Green" -> "Go"
    trafficLightState == "Yellow" -> "Slow Down"
    trafficLightState == "Red" -> "Stop"
    else -> "Malfunction"
}
println(trafficAction)
```

```kotlin
val trafficLightState = "Red"
val trafficAction = when (trafficLightState){
    "Green" -> "Go"
    "Yellow" -> "Slow Down"
    "Red" -> "Stop"
    else -> "Malfunction"
}
println(trafficAction) // "Stop
```

### Ranges

일반적인 연산범위 설정은 ".." 사용하며 Char 타입도 적용

Ex) 1..4 -> 1, 2, 3, 4

Ex) 1..<4 -> 1, 2, 3

Ex) 4 downTo 1 -> 4, 3, 2, 1

Ex) 1..5 step 2 -> 1, 3, 5

Ex) 'a'..'d' -> 'a', 'b', 'c', 'd'

Ex) 'z' downTo 's' step 2 -> 'z', 'x', 'v', 't'

### Loops - while

while은 2가지 방법으로 사용할 수 있다.
1. 조건이 참인 블록 실행
2. 먼저 코드 블록을 실행한 다음 조건 확인

```kotlin
var cakesEaten = 0
while (cakeEaten < 3){
    print("eat a cacke")
    cakesEaten++
}
```

2번은 do-while을 사용
1. while 루프가 실행될 조건식을 () 안에 선언
2. {}를 사용하여 수행할 동작 정의
```kotlin
var cakesEaten = 0
var cakesBaked = 0
while (cakesEaten){
    print("eat a cacke")
    cakesEaten++
}
do {
    print("bake a cacke")
    cakesBaked++
} while (cakesBaked < cakesEaten)
```

## functions

함수의 파라미터를 String Template(Python Formatting)으로 받을 수 있음
```kotlin
fun printMessageWithPrefix(message: String, prefix: String) {
    println("[$prefix] $message")
}

fun main(){
    printMessageWithPrefix(prefix = "Log", message = "Hello")
}
```

파라미터 기본값 사용
```kotlin
fun printMessageWithPrefix(message: String, prefix: String = "Info") {
    println("[$prefix] $message")
}

fun main(){
    printMessageWithPrefix(prefix = "Log")
}
```

간결하게도 함수 선언 가능
```kotlin
fun sum(x: Int, y: Int) = x + y
fun main(){
    println(sum(1,2))

```

kotlin도 lambda 함수가 존재
람다 표현식은 {}안에 작성되며 파라미터 뒤에 "->" 이게 오고, 그 다음 함수 본문이 옴
{파라미터 -> 본문} 형태면 무조건 람다함수
```kotlin
As-Is
fun upperCaseString(text: String): String {
    return text.upperCase()
}

fun main(){
    println(upperCaseString("hello"))
}

To-Be
fun main(){
    val upperCaseString = {text: String -> text.upperCase()}
    println(upperCaseString("hello"))
}
```

```kotlin
val numbers = listOf(1, -2, 3, -4, 5, -6)
val positives = numbers.filter( { x -> x>0})
val isNegative = {x -> x<0}
val nagatives = numbers.filter(isNegative)

filter가 람다 표현식을 조건으로 받아들이고, 리스트 요소에 적용
```

```kotlin
val numbers = listOf(1,-2,3,-4,-5,-6)
val doubled = numbers.map{x -> x*2}
val isTripled = {x -> x * 3}
val triped = numbers.map(isTripled)

map -> 각 컬렉션의 요소를 변환해서 새로운 리스트를 만드는 함수
```

람다 함수내 매개변수 타입은 ()안에쓰고 ","로 추가
(String) -> String
(Int, Int) -> Int
```kotlin
val upperCaseString: (String) -> String = {text -> text.uppercase()}

매개변수 없으면 () 비워둠
val upperCaseString = {str -> str.uppercase()}
```

람다 함수는 함수로부터 리턴도 가능
```kotlin
fun toSeconds(time: String): (Int) -> Int = when (time){
    "hour" -> {value -> value * 60 * 60}
    "minute" -> {value -> value * 60}
    "second" -> {value -> value}
    else -> {value -> value}
}
fun main(){
    val timesInMinutes = listOf(2, 10, 15, 1)
    val min2sec = toSeconds("minute")
    val totalTimeInSeconds = timesInMinutes.map(min2sec).sum()
}
```

람다함수를 선언하면서 바로 파라미터 넣어서 호출도 가능
```kotlin
println( {text: String -> text.uppercase()} ("hello"))
```

Trailing Lambda
함수의 마지막 파라미터가 람다일때 () 밖으로 빼서 쓸 수 있는 문법
* fold(0) 주목
```kotlin
println(
    listOf(1,2,3).fold(0, {x, item -> x + item})
)
println(
    listOf(1,2,3).fold(0)  {x, item -> x + item})
)
```
