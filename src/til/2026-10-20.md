## Null Safety

### 스마트 캐스트와 안전한 캐스트

* 캐스팅 - 이 값을 특정 타입으로 취급해라라고 코틀린에서 사용

```kotlin
fun describe(x: Any){
    when (x){
        // is는 이 타입이 맞냐? !is는 이 타입이 아닌가?
        is String -> println("문자열")
        is Int -> println("정수")
        !is Boolean -> println("not bool")
        else -> println("bool")
    }
}
fun main(){
    describe("hello") // is String
    describe(21)      // is Int
    describe(3.14)    // !is Boolean
    describe(true)    // else
}
```

### as 와 as? 캐스팅

직접 이 타입으로 바꿔할때는 as 사용

```kotlin
val a: Any = "hello"
val b = a as String // 진짜 String이라 성공
println(b.length) // 5

val c: Any = 123
val d = c as String // Int는 String이 아니라서 에러

val c: Any = 123
val d = c as? String // String이 아니니까 null
println(d) // null
```

### as? + ?. + ?: 조합

이 세개를 같이 쓰면 여러줄 코드를 한 줄로 줄일 수 있다.

```kotlin
fun totalLength(items: List<Any>): Int { 
    var total = 0
    for (item in items){
        if (item is String) total += item.length
    }
    return total
}

fun totalLength(items: List<Any>): Int = items.sumOf{(it as? String?.length) ?: 0}
```

1. it as? String -> String이면 그대로, 아니면 null
2. ?.length는 null이 아니면 길이를, null이면 그냥 null 리턴
3. ?: 0 은 결과가 null이면 0, 아니면 왼쪽 값

### null 걸러내기

1. filterNotNull() - 리스트에서 null빼고 리턴

```kotlin
val scores: List<Int?> = listOf(90, null, 75)
scores.filterNotNull() // 90, 75
```

2. listOfNotNull() - 리스트 만들때부터 null 제거
```kotlin
val menu = mapOf("커피" to 4000, "라떼" to 4500)
val prices = listOfNotNull(menu["커피"], menu["라떼"], menu["123"]) // 4000, 5000
```

### 못 찾으면 null을 주는 함수들

OrNull이 붙은 함수들은 찾으면 그 값, 못 찾으면 null 리턴

```kotlin
val temps = listOf(12, 15, 16, 55)
temps.maxOrNull() // 55
temps.minOrNull() // 12

val empty = listOf<Int>()
println(empty.maxOrNull() ?: "데이터 없음")
```

```kotlin
val nums = listOf(1, 2, 3, 4)
nums.singleOrNull {it > 3} // 4
nums.singleOrNull {it > 2} // null
nums.singleOrNull {it > 9} // null
```

```kotlin
data class Member(val nickname: String?)
val members = listOf(
    Member(null), Member("코틀린"), Member("자바")
)
// firstNotNullOfOrNull는 원소를 람다로 변환하면서 null 아닌 첫 번째 값
members.firstNotNullOfOrNull() {it.nickname} // 코틀린
```

```kotlin
var cart = listOf(1000, 2500, 3000)
// reduceOrNull는 빈리스트에서 쓰면 에러남
cart.reduceOrNull {total, price -> total + price} // 6500

val emptryCart = listOf<Int>()
emptyCart.reduceOrNull {total, price -> total + price} ?: "장바구니 비어 있음"
```

### takeIf

조건이 참이면 원래 값 그대로, 거짓이면 null

```kotlin
val age = 20
age.takeIf { it >= 19} // 20
age.takeIf { it > 30 } // null
```
