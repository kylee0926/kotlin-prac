## Properties

속성에는 숨겨진 get() / set()이 있음

person.name처럼 값을 읽거나, person.name = "철수"라고 할 때 내부에선 get() set()이 호출되는중

```kotlin
class Product {
    var price: Int = 0
}
이 코드는 사실 아래처럼 구성되어 있음

set에서 매개변수로 field를 써야 함

그리고 이렇게 값이 실제로 저장되는 공간을 backing field라고 하며 접근자 안에서는 field라는 키워드로 접근
        
class Product {
    var price: Int = 0
        get() = price
        set(field) {
            field = value
        }
}
```

클래스에서도 가능

```kotlin
class Rect(val width: Int, val height: Int)

// Rect 클래스는 건들지 않았는데, 이렇게 쓸 수 있음
val Rect.area: Int
    get() = this.width * this.height

fun main(){
    val rect = Rect(3, 4)
    println(rect.area) // 12
}
```

### 위임 속성 (Delegated Properties)

클래스는 ```: Printer by p```처럼 인터페이스 구현을 위임했었는데, 속성의 get() set()을 다른 객체에 맡기는 것이 가능

```kotlin
class CountingDelegate{
    var count = 0
    
    """
    operator: 이 함수는 속성 읽기/쓰기에 연결되는 특별한 함수
    thisRef: 위임 속성을 가진 객체(여기선 Note)
    """
    operator fun getValue(thisRef: Any?, property: Any?): String {
        count ++
        return "$count 읽음"
    }
}

class Note {
    val info: String by CountingDelegate()
}

fun main(){
    val note = Note()
    
    // note를 읽을때마다 CountingDelegate의 getValue()가 호출됨
    println(note.info) // 1 읽음
    println(note.info) // 2 읽음
}
```

### 표준 위임 (Standard Delegates)

위임 객체를 매번 만들 필요 없고, 이걸 쓰면 getvalue() / setValue() 직접 안 만들어도 됨

* lazy: 처음 쓸 때 초기화
* observable: 값이 바뀔때 방지


```kotlin
var config: String by lazy {
    println("loading")
    "darkmode" // lambda 마지막 값이 속성 값
}
fun main(){
    println("start")
    println(config) // loading -> darkmode
    println(config) // darkmode (람다 재실행 안함)
}
```

```kotlin
import kotlin.properties.Delegates.observable

class Game {
    var score: Int by observable(0) {_, old, new -> println("점수 번경 $old -> $new") if (new >= 100) println ("렙압")}
}
fun main(){
    val game = Game()
    game.score = 50 // 점수변경 0 -> 50
    game.score = 100 // 점수변경 50 -> 100
}
```

observable(0)에서 초기 값은 0이라는 뜻이다. 그리고 람다는 매개변수가 3개인데, 속성정보-이전값-새값을 나타냄

속성정보는 안 쓰니까 _ 로 채움
