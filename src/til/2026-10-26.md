### checked exceptions

예의는 Exception 클래스의 자식들로 표현되고, Exception은 Throwable의 자식

throw로 직접 예외 던질 수 있으며, 예외도 객체라서 클래스로 만들어야 함

```kotlin
throw IllegalArgumentException()
```

전제조건 함수로 예외 던지기  - if (..) throw 대신 사용 가능한 문법

* require(): 입력값이 올바른지 검사 - IllegalArgumentException
* check(): 객체나 변수의 상태가 올바른지 검사 - IllegalStateException
* error(): 일어나면 안 되는 상황임을 알림 - IllegalStateException

```kotlin
fun makeStars(count: Int): String {
    require(count >= 0) { "count는 0 이상이어야 해요. 입력값: $count" }
    return "*".repeat(count)
}

fun main() {
    println(makeStars(3))    // ***
    println(makeStars(-1))   // IllegalArgumentException 발생
}

class Player {
    var isLoggedIn = false

    fun startGame() {
        check(isLoggedIn) { "로그인 후에 게임을 시작할 수 있어요" }
        println("게임 시작!")
    }
}

fun main() {
    val player = Player()
    player.isLoggedIn = true
    player.startGame()   // 게임 시작!
}

fun getDiscount(grade: String): Int = when (grade) {
    "VIP" -> 20
    "GOLD" -> 10
    "SILVER" -> 5
    else -> error("알 수 없는 등급: $grade")
}

fun main() {
    println(getDiscount("GOLD"))     // 10
    println(getDiscount("BRONZE"))   // IllegalStateException 발생
}
```

### Types overview

* Any: 코틀린 클래스 계층의 취상위 조상으로 아무 타입이나 받음
* Unit: 값이 딱 하나뿐인 타입으로 의미있는 반환값이 없다
* Nothing: 값이 하나도 없음, 정상적으로 끝나지 않음을 의미하며 when else -> error()가 가능한게 이것때문

### static

kotlin은 static 문법이 없으며 대신 아래 4개를 사용

* companion object
* top-level function
* 확장 함수
* @JvmStatic - java에서 kotlin을 호출할때를 위한 것


```kotlin
// companion object
class MathUtil {
    companion object {
        fun square(x: Int) = x * x
    }
}

MathUtil.square(3)   // 자바의 static처럼 클래스 이름으로 호출

// top-level function
fun square(x: Int) = x * x   // 클래스 없이 파일에 바로

fun main() {
    println(square(3))   // 9
}

// 확장 함수
// 자바 방식이라면: StringUtil.bold("hello")
// 코틀린 방식:
fun String.bold() = "<b>$this</b>"

"hello".bold()

// jvmstatic
class MathUtil {
    companion object {
        @JvmStatic
        fun square(x: Int) = x * x
    }
}
```

### wildcard types

String은 Any의 자식인데, List<String>도 List<Any> 자리에 넣을 수 있을까?

```kotlin
fun addNumber(items: MutableList<Any>) {
    items.add(42)   // Any 리스트니까 Int를 넣어도 됨
}

val names: MutableList<String> = mutableListOf("철수")
addNumber(names)   // ❌ 에러!
```

addNumber로 42를 넣는데, names는 문자열이 있어서 문제가 생김

그래서 자바는 와일드카드로 "?" 사용

```java
// 자바
void printAll(List<? extends Object> items) { ... }
```

* ? extends object
  * object 또는 그 자식 타입의 리스트면 된다.

다만, 문제는 이걸 쓸 때 마다 매번 붙여야해서 코드가 복잡해지고, 이를 해결하기 위한 코틀린 방법이 있음

kotlin의 방식 1. 선언 지점 변경
* out T -> 이 클래스는 T를 꺼내주기만 하고 받지 않는다.
* In T -> 이 클래스는 T를 받기만 하고 꺼내지는 않는다.
```kotlin
interface Box<out T> {
    fun get(): T        // T를 꺼내기만 함 (내보내기 = out)
}
interface Printer<in T> {
    fun print(item: T)   // T를 받기만 함 (들어오기 = in)
}
```

kotlin의 방식 2. 타입 프로젝션
* MutableList는 out을 붙일 수 없음
* 사용하는 곳에서 "여긴 꺼내기만 한다." 라고 표시 가능 -> 이걸 타입 프로젝션이라고 함
```kotlin
fun printAll(items: MutableList<out Any>) {
    for (item in items) println(item)   // 꺼내기는 됨
    // items.add(42)                    // 넣기는 막힘
}

val names: MutableList<String> = mutableListOf("철수")
printAll(names)   // ✅ 됨
```

### Records

데이터를 담기만 하는 클래스를 짧게 만든 문법

```java
record User(String name, int age){}
```

```kotlin
data class User(val name: String, val age: Int)
```
