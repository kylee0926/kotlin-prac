### data class

kotlin은 데이터를 저장하는데 유용한 데이터 클래스가 있음. class 앞에 data만 붙이면 됨
python의 @dataclass와 같은 역할 (init, repr, eq, hash를 직접 안 써도 됨)

```kotlin
data class User(val name: String, val id: Int)
```

```python
@dataclass
class User:
    name: str
    id: int
```

왜 필요한가?
1. 일반 class는 "메모리 주소가 같아야 같은 객체", data class는 "값이 같으면 같은 객체"
2. 일반 class는 println하면 `User@3d4eac69`처럼 주소만 나와서 안에 뭐가 있는지 모름
3. toString, equals, hashCode를 직접 쓰면 30줄쯤 되고, 필드 추가할 때마다 전부 고쳐야 함

data class가 자동으로 만들어주는 것

1. toString(): 내용이 보이게 출력 (python `__repr__`)
```kotlin
class Plain(val name: String, val id: Int)
data class User(val name: String, val id: Int)

val user = User("Alex", 1)

println(Plain("Alex", 1)) // Plain@3d4eac69
println(user)             // User(name=Alex, id=1)
```

2. equals() / hashCode(): 값으로 비교 (python `__eq__`, `__hash__`)
```kotlin
val user = User("Alex", 1)
val secondUser = User("Alex", 1)
val thirdUser = User("Max", 2)

println(Plain("Alex", 1) == Plain("Alex", 1)) // false  (일반 class는 주소 비교)
println(user == secondUser)                   // true   (값이 같으면 같음)
println(user == thirdUser)                    // false

// hashCode 덕분에 Set, Map, contains도 값 기준으로 동작함
println(setOf(user, secondUser).size)                       // 1
println(listOf(user, thirdUser).contains(User("Max", 2)))   // true
```

3. copy(): 일부만 바꾼 복사본 생성 (python `dataclasses.replace()`)
```kotlin
println(user.copy())        // User(name=Alex, id=1)
println(user.copy("Max"))   // User(name=Max, id=1)
println(user.copy(id = 3))  // User(name=Alex, id=3)
```
val로 불변 객체를 만들어도 copy로 값 바꾼 새 객체를 쉽게 만들 수 있음

4. componentN(): 구조 분해 (python 튜플 언패킹)
```kotlin
val (name, id) = user
println("$name / $id") // Alex / 1
```

제약
1. 주 생성자에 파라미터가 1개 이상 있어야 하고, 전부 val 또는 var여야 함
2. abstract, open, sealed, inner 불가 (상속의 부모가 될 수 없음)
3. 자동 생성은 주 생성자 프로퍼티만 대상. 클래스 본문 `{}` 안에 선언한 프로퍼티는 toString, equals에 포함 안 됨

언제 쓰나?
- API 응답, DB 레코드, 화면 상태처럼 "데이터 덩어리"는 거의 전부 data class
- Repository, Service처럼 동작이 중심인 클래스는 일반 class

### Elvis Operator

"?:"를 사용하는 문법으로 왼쪽이 null이면 오른쪽 값을 써라라는 의미


```kotlin
fun main(){
    val nullString: String? = null
    println(nullString?.length ?: 0)
}

fun process(input: String?){
    val text = input ?: return
    val n = text.toIntOrNull() ?: throw Exception("숫자아님")
}
```
