### 변수
* val 은 read-only
* var 은 Mutable

이렇게 하면 customers는 mutable하므로 8이 나온다.
```kotlin
fun main() {
    val popcorn = 5
    val hotdog = 7
    var customers = 10

    customers = 8
    println(customers)
}
```

근데 hotdog는 read-only여서 이대로 실행하면 에러 발생
메시지는 "Kotlin: 'val' cannot be reassigned."
```kotlin
fun main() {
    val popcorn = 5
    val hotdog = 7
    var customers = 10

    hotdog = 8
    println(customers)
}
```

### String Templates
파이썬의 Formatting과 같은 기능

```kotlin
val customers = 10
println("There are $customers customers")
// There are 10 customers

println("There are ${customers+1} customers")
// There are 11 customers
```

변수만 사용할때는 ```$```만 앞에 붙이고, 연산이 있을때는 ```${변수 + 숫자}```이런식으로 한다.

## Collections
나중에 처리하기 쉽도록 데이터를 구조별로 그룹화하며, 이게 컬렉션

* Lists
* Sets
* Maps

### List
파이썬과 다르게 코틀린은 읽기 전용 리스트와 수정 가능 리스트가 나뉘어져 있다.

* Read only - listOf()
* Mutable - mutableListOf()
그리고 리스트안의 데이터 타입을 추론할 수 있는데, <> 기호를 붙인다.

```kotlin
val readOnly = listOf("triangle", "square")
val shapes: MutableList<String> = mutableListOf("triangle", "circle")

println("First is ${readOnly[0]}")
println("First in ${readOnly.first()}")
println("Last is ${readOnly.last()}")
println("total is ${readOnly.count()} items")
shapes.add("pentagon")
shaes.remove("pentagon")
```

### Set
python set과 동일하게 순서 보장 안되고, 중복 허용 안함

코틀린의 List처럼 ReadOnly(setOf), Mutable(mutableSetOf)이 있으며 <>로 타입 명시 가능

```kotlin
val readOnly = setOf("apple", "banana")
val fruit: MutableSet<String> = mutableSetOf("cherry", "pi")
println("total is ${readOnly.count()}")
fruit.add("apple")
fruit.remove("apple")
```

### Map
python dict처럼 key-value 형태로 데이터 구조 이루어져 있음
이거도 List처럼 Readonly(mapOf), Mutable(mutableMapOf)로 나뉘어져 있음

```kotlin
val readOnly = mapOf("apple" to 1000, "kiwi" to 190)
val menu: MutableMap<String, Int> = mutableMapOf("apple" to 100, "kiwi" to 90)
println("apple is ${readOnly["apple"]}")
menu["strawberry"] = 1090
menu.remove("strawberry") // 다른 키 써도 아무 일 안남
print("total is ${menu.count()}")
menu.containsKey("strawberry") // 특정 키가 있나 체크
menu.keys // key만 mutable set으로 리턴
menu.values // value만 mutable collection으로 리턴
```
