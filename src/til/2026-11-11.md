## 틀린 것

| 틀린 것 | 맞는 것 | 어디서 온 습관 |
|---|---|---|
| `fun hello: String(...)` | `fun hello(...): String` — 이름 → (파라미터) → : 반환 타입 | |
| `RequestParam("name") name` | `@RequestParam("name") name: String` — 어노테이션은 앞, 타입만 뒤 | |
| `""" """` 를 주석으로 | `/* */`. `""" """` 는 여러 줄 문자열 | Python |
| `operator class Hello` | `class Hello`. 중첩 클래스는 기본이 static, 바깥 참조가 필요하면 `inner` | |
| `val` 에 재대입 | `var`, 또는 생성자에서 받아 `val` 유지 | |
| getter/setter 를 함수로 옮김 | 지우고 주 생성자 프로퍼티로 | Java 번역 |
| `class A(B)` | `class A : B`. 괄호는 주 생성자 자리 | Python |
| `MutableMapOf<>` 를 타입으로 | 타입은 `MutableMap`, 만드는 함수는 `mutableMapOf()` | |
| `store[member.id]` | `store[id]`. `member.id` 는 `Long?` 라 `Long` 키에 못 씀 | |
| `filter(m -> ...)`, `findAny()` | `filter { }`, `firstOrNull { }` | Java |
| `listOf(컬렉션)` | `.toList()`. `listOf(x)` 는 x 하나가 든 리스트 | |
| 람다 파라미터로 `this` | `it` 또는 직접 지은 이름 | |
| 인터페이스에 없는 함수에 `override` | `override` 는 부모에 선언된 것만 | |

## this vs it

| | `this` | `it` |
|---|---|---|
| 뜻 | 이 코드가 속한 객체 | 파라미터 하나인 람다에서 그 파라미터의 자동 이름 |
| 쓰는 곳 | 클래스의 함수·프로퍼티 안 | 람다 `{ }` 안에서만 |
| Python | `self` | `lambda m: ...` 의 `m` |
| 생략 | 가능 (`this.store` == `store`) | 이름을 지으면 안 씀 (`{ member -> ... }`) |

`store.values.firstOrNull { it.name == name }` 에서 `store` 앞의 숨은 `this` 는
`MemoryMemberRepository`, `it` 은 꺼내 본 `Member` 한 개.

## 정리한 규칙

**Member 변환 순서**
1. getter/setter 에 로직이 없으면 지운다
2. 프로퍼티는 주 생성자에 `val`/`var` 로 선언한다
3. 값이 없는 상태가 실제로 있을 때만 `?` 를 붙인다 (`id` 는 저장 전엔 없다)
4. 인자 없이 만들어야 하면 기본값을 준다

결과: `class Member(var id: Long? = null, var name: String = "")`

**그 밖**
- 중괄호 본문 함수는 반환 타입을 꼭 쓴다. `=` 로 쓰는 식 본문은 추론된다
- `val` 은 "변수가 다른 걸 가리키지 않는다"이지 "내용이 안 바뀐다"가 아니다.
  `val store = mutableMapOf()` 는 내용 수정 가능
- `Optional<T>` 는 `T?` 로. `store[id]` 는 키가 없으면 null 이라 `Optional.ofNullable` 불필요
- 문자열은 `"hello $name"`, 식이면 `"${member.name}"`

## 완성본 (MemoryMemberRepository)

```kotlin
class MemoryMemberRepository : MemberRepository {
    val store = mutableMapOf<Long, Member>()
    var sequence = 0L

    override fun save(member: Member): Member {
        val id = ++sequence
        member.id = id
        store[id] = member
        return member
    }

    override fun findById(id: Long) = store[id]
    override fun findByName(name: String) = store.values.firstOrNull { it.name == name }
    override fun findAll() = store.values.toList()
    fun clearStore() = store.clear()
}
```
